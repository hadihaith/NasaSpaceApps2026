# Homecoming typography

Bundled static TrueType fonts, loaded locally at runtime. No OS fonts or network
requests are required during play.

| Asset | Typeface | Purpose | Source |
| --- | --- | --- | --- |
| `Display.ttf` | Barlow Condensed ExtraBold | Mission-poster titles and scene lettering | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/barlowcondensed) |
| `Body.ttf` | Barlow Medium | Buttons, dialogue and longer text | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/barlow) |
| `Mono.ttf` | IBM Plex Mono Regular | Instrument labels and navigation | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/ibmplexmono) |
