# Dr. Nyxen

Open `dr-nyxen.blend` in Blender 4.5 LTS to edit the model or animate its 32-bone FK rig. The original sprite sheet is packed in the hidden **Source reference** collection. The **Preview studio** collection contains the cameras and lights for the renders. Use the Action Editor to select a saved action.

The game asset is served at `/assets/characters/dr-nyxen.glb`. It is a self-contained skinned glTF model with +Y up, +Z forward, and its origin at the feet. It stands 3.03 scene units tall at scale 1.

| Clip | Playback |
| --- | --- |
| `Idle` | Loop the head, antenna, torso, and coat motion. |
| `Explain` | Play once for a two-handed explanation. |
| `Eureka` | Play once for a raised-finger reaction. |

The rig includes independent eye aim, antenna, hand, finger, and coat-tail bones. The mouth and eyelids keep the sculpted expression. Coat movement uses the two tail bones and the supplied poses.
